# 04: 解释自动调价为何执行或保持原价

Status: ready-for-human
Progress: implemented-and-verified
Blocked by: 03
Spec: [策略预演与行情分析：第一版](../spec.md)
User stories: 2, 8–10, 12, 28–29, 33

**What to build:** 使用者可以查看某件在售物品的自动调价检查，理解为何建议降价、保持原价或等待，以及实际撤单重挂是否已发生。

## Acceptance criteria

- [x] 真实自动调价检查接入检查记录列表与详情，复用 03 的出售规则解释，并记录挂售时间、当前价、建议价、价差、原始购买成本及底线等已有依据。
- [x] 记录并解释实际检查中的未到评估时间、价差不足、触及底线、策略限制及数据不可用；不能仅保存最终允许调价的情况。
- [x] 未到行情查询阶段时保持原有提前停止，不为了生成解释额外请求行情；没有建议价时显示尚未计算及对应原因。
- [x] 页面区分调价判断与撤单、返库、重新上架等执行结果，不把建议降价表述为已经完成调价。
- [x] 调价详情只读，不提供专属参数试改或保存控件；公开预演接口对调价试改请求明确拒绝，不能退化成普通上架预演。
- [x] 查看解释不创建或推进调价任务，不改变正式调价设置或交易流水；不扩展既有自动调价支持的币种与资产范围。
- [x] 通过真实调价检查、公开记录接口和浏览器验证主要原因与只读边界；测试中禁止实际撤单、上架和确认。

## Implementation notes

本票依赖普通上架的规则解释能力，不依赖主动刷新或走势图。自动调价专属参数的预演明确不属于首版。
