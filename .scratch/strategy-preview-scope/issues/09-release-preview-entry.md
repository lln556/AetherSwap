# 09: 切换正式入口并完成首版整体验收

Status: ready-for-human
Progress: implemented-and-verified
Blocked by: 04, 05, 06, 07, 08
Spec: [策略预演与行情分析：第一版](../spec.md)
User stories: 2–6, 11, 33, 37, 41–42

**What to build:** 策略中心正式使用检查记录与预演替代示例模拟，使用者可在桌面或手机完成查找真实检查、理解原因、比较参数、刷新行情和另存副本的完整流程。

## Acceptance criteria

- [x] 现有示例模拟入口替换为检查记录与预演；保留已有策略，不另留混淆真实结果的示例演示入口。
- [x] 旧的无检查记录模拟请求返回明确提示，不再产生固定示例通过；现有策略查看、编辑和启用流程继续可用。
- [x] 买入、普通上架和自动调价记录均可按类型、商品名称和结果筛选并分页；列表显示检查时间、商品、所用策略和结果摘要。
- [x] 无记录时明确显示空状态并说明记录从新功能启用后产生；不从旧日志补造完整记录，不为未进入逐件检查的商品虚构结果。
- [x] 桌面与手机都能完成记录筛选、原因阅读、参数比较、数据刷新和另存副本；自动调价页面保持只读解释。
- [x] 完成成本率 74%、上限 70% 改为 75% 的完整流程：单项拒绝变通过，缺少历史数据时停止，主动刷新后两套参数及图表使用同一新版本，原解释仍可查看。
- [x] 联动验证清理与刷新：记录在刷新期间被清理或任务恢复时不可用，应明确失败，不复活过期记录或遗留无归属版本。
- [x] 联动验证保存副本不改变正式策略和启用状态；所有预演与刷新均没有交易或调价任务副作用，图表不触发隐式行情请求。
- [x] 运行相关接口、数据库、浏览器和完整回归，以及前端语法检查；验证使用隔离数据库与合成平台响应，不操作真实账户。
- [x] 对照父 spec 检查所有用户故事及范围边界，记录验证结果和剩余限制；实现、提交、推送和部署分别报告，不自动部署或启动交易。
