# 06: 展示与判断对应的价格和成交量走势图

Status: ready-for-human
Progress: implemented-and-verified
Blocked by: 02, 03
Spec: [策略预演与行情分析：第一版](../spec.md)
User stories: 12–15, 41

**What to build:** 使用者在买入和普通上架详情中，通过简单的价格及成交量走势理解判断依据，知道图表对应哪份数据、什么时间范围和币种。

## Acceptance criteria

- [x] 在已有真实买入和普通上架记录详情中展示价格与成交量图表，使用记录本身保存的历史数据，不为打开图表隐式刷新行情。
- [x] 图表与当前展示的规则结果使用同一数据版本，明确标注来源、采集时间、分析窗口和币种；不重新查询当前配置改变旧图表的解释。
- [x] 历史数据不足、存在缺口或没有成交量时明确提示，不插值伪装真实成交，不生成示例曲线。
- [x] 图表作为理解判断的辅助，与实际值、阈值和通俗原因一起呈现，不改变规则计算输入或引入新的交易算法。
- [x] 沿用现有原生前端和视觉规范；桌面及手机都可辨认图表、单位、范围和缺失说明，不增加独立大盘研究页面。
- [x] 通过公开详情数据与真实浏览器页面验证数据版本一致性、币种及时间标记、缺口、空状态和移动端展示；固定数据下无网络获取副作用。

## Implementation notes

本票可在主动刷新完成前独立演示，故不依赖 05；读取共用数据版本，05 接入后由 09 验证刷新版本的图表联动。
