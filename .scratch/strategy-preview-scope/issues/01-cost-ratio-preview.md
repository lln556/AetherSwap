# 01: 打通真实成本率检查到参数预演

Status: ready-for-human
Progress: implemented-and-verified
Blocked by: None (can start immediately)
Spec: [策略预演与行情分析：第一版](../spec.md)
User stories: 1, 4, 7–10, 12, 16, 18–22, 30, 33–34, 37–38, 40

**What to build:** 使用者可以从一次真实买入成本率检查进入详情，看到当时的依据，并临时修改成本率上限比较结果。交付从真实检查、记录保存、公开接口到可操作界面的最小完整路径，不把单项通过显示成整个策略通过。

## Acceptance criteria

- [x] 正式成本率判断与预演使用共用规则。先完成这一小段规则的提取与行为保持验证，再接入记录和预演；不进行全仓范围重构。
- [x] 一次真实逐件检查可以生成持久记录，保存账号和商品标识、评估时刻、完整有效策略及模块版本、计算所需的业务输入和结果；兼容现有 SQLite、PostgreSQL 初始化方式。
- [x] 通过受现有 API 鉴权保护的列表与详情接口及页面，可看到检查时间、商品、策略、实际成本率、阈值、结果和原因。初始入口与原模拟功能可暂时并存，正式替换由 09 完成。
- [x] 共用记录能承载买入、普通上架、自动调价类型，以及原检查和关联数据版本；后续任务扩展这些行为时不改变固定数据比较原则。
- [x] 固定样本成本率为 74%：上限 70% 时该项拒绝，临时改为 75% 时该项通过；同一数据版本上同时展示原参数与临时参数，并突出差异。
- [x] 记录保留完整有效策略，但本票只保证成本率规则的预演。其他步骤明确标注未执行、缺数据或暂不支持，不能返回整个策略通过。
- [x] 修改临时参数、实际时间流逝、当前配置变化和后续行情变化，不改变原检查依据。固定输入预演不调用网络，不增删、排序或启停模块，也不修改正式策略。
- [x] 重启后可读取记录。记录不含 Cookie、令牌密钥、支付链接或完整运行配置；写入失败不改变正式成本率判断，并报告记录不可用。
- [x] 通过真实检查流程和公开接口验证记录、参数比较及无交易副作用；浏览器能够完成上述最小流程。使用隔离数据库与合成平台响应，不操作真实账户。

## Implementation notes

本票定义供其他切片使用的最小共用记录和比较能力。完整买入规则由 02 扩展，保留与清理策略由 08 完成；不得为这些后续能力提前宣称验收通过。
