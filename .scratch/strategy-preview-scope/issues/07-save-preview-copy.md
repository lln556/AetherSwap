# 07: 将预演参数另存为未启用的策略副本

Status: ready-for-human
Progress: implemented-and-verified
Blocked by: 01
Spec: [策略预演与行情分析：第一版](../spec.md)
User stories: 30–32, 42

**What to build:** 使用者对临时参数满意后，可保存为新的自定义策略，再进入现有策略中心决定是否启用。原策略和正在运行的任务不会因另存而变化。

## Acceptance criteria

- [x] 在买入或普通上架的共用预演详情中提供另存副本操作，使用原记录的完整有效策略结构及合法临时参数，生成新的自定义策略标识。
- [x] 复用现有策略验证，不允许通过另存增删、排序或启停模块；原策略名称或标识不得导致覆盖已有策略。
- [x] 保存结果在现有策略中心可见，界面明确提示尚未启用，并提供前往查看的入口。
- [x] 保存前后原策略内容、所有启用策略标识及运行配置保持不变，不自动启用新策略，不修改调价设置。
- [x] 离开、取消或保存失败时，临时参数不会写入正式配置；失败原因明确，不能错误提示已经保存。
- [x] 自动调价只读记录不提供此操作。遇到无法支持的旧策略或模块版本时明确提示，不能静默用当前配置替换记录依据。
- [x] 通过公开保存和策略查询接口以及浏览器验证新副本可见、有效参数正确、原策略未变、未自动启用和取消无副作用。

## Implementation notes

依赖 01 建立的完整策略记录和参数接口即可实现保存行为，不要求所有规则预演已经完成。02、03 接入后由 09 验证两类完整流程。
