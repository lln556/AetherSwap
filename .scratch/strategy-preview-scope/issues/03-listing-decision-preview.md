# 03: 支持普通上架的决策解释与参数预演

Status: ready-for-human
Progress: implemented-and-verified
Blocked by: 01
Spec: [策略预演与行情分析：第一版](../spec.md)
User stories: 8–10, 12, 17–22, 30, 33

**What to build:** 使用者从本系统库存的真实出售检查中了解为什么上架或等待、建议价格如何得出，并用同一份数据比较出售参数的影响，而不提交上架。

## Acceptance criteria

- [x] 真实普通上架检查生成与 01 共用格式的记录，保存购买、库存、挂单、价格和策略判断所需上下文，以及有效策略、数据来源和时间。
- [x] 正式出售与预演共用归属、挂单数量、价格墙及断层定价、趋势、成本保护和安全声明式模块规则，不改变正式检查顺序与算法。
- [x] 页面可查看上架、暂缓和拒绝的理由，区分未执行、未启用、数据不可用及不支持；有定价结果时注明买家价格、预计到账及对应币种。
- [x] 原参数与临时出售参数使用相同库存、挂单和行情依据；不能改用当前库存或忽略原购买记录的归属条件。
- [x] 缺少历史行情、汇率或其他必要上下文时明确无法判断，不用人民币数值代替外币数值；存在的历史行情可供后续图表使用。
- [x] 参数比较不接受增删、排序或启停模块，不改变正式策略、库存状态、上架记录或调价设置。
- [x] 对相同输入及评估时刻，公开预演结果与真实出售检查结果一致；覆盖建议定价、趋势等待、同名挂单限制、归属不明和数据缺失。
- [x] 隔离测试禁止上架、撤单及移动确认；浏览器能够进入真实出售记录、阅读原因并比较临时参数。

## Implementation notes

本票只覆盖普通上架；不提供自动调价专属设置试改。共用的出售解释结果由 04 复用于自动调价。
