# Triage 标签

各 skills 使用五种标准 triage 角色。本文件将标准角色映射到本仓库 issue tracker 中实际使用的状态字符串。

| mattpocock/skills 中的角色 | 本仓库使用的状态 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要评估此 issue |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 已完整定义，可交给 AI agent 执行 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 确认不会处理 |

当 skill 提到某个 triage 角色时（例如“应用 AFK-ready triage 标签”），使用上表对应列中的状态字符串。
