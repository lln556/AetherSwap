# 使用 Chrome 扩展导入 BUFF 登录会话

2026-10-30，用户确认采用安装 Chrome 扩展的方式，将本地浏览器已有的 BUFF 登录会话导入 AetherSwap。普通网页无法直接取得其他域的完整登录 Cookie；相较于继续手工复制或维护网页内远程登录浏览器，扩展方案更符合复用本地登录的目标。

用户随后确认首版采用扩展文件包手动安装，仅支持同一 Chrome 个人资料的普通窗口。扩展在用户主动操作并确认已授权的目标来源后才读取、传送会话，不做后台同步；授权精确到协议、主机与端口。

服务器校验会话及绑定 Steam 账号，匹配当前账号且验证成功才保存；失败保留原凭据，不能自动切换账号。浏览器已登录与服务器会话有效分别处理，扩展取得 Cookie 不作为验证通过的证据。

完整范围见 `.scratch/buff-session-entry/design.md`；用户已最终确认整体设计与实施，按该范围交付。
